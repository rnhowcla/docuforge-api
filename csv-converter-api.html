CSV File Processing API

Convert and clean CSV files through simple REST API calls. No need to open Excel or install any desktop software.

CSV to Excel

curl -X POST http://[2409:893d:dcd:8c60:3058:eb94:1d9:c7fa]:5000/api/v1/csv/to-excel \
  -H "X-API-Key: YOUR_KEY" \
  -F "file=@data.csv" -o output.xlsx

Clean CSV Data

curl -X POST http://[2409:893d:dcd:8c60:3058:eb94:1d9:c7fa]:5000/api/v1/csv/clean \
  -H "X-API-Key: YOUR_KEY" \
  -F "file=@raw.csv" -o cleaned.csv
