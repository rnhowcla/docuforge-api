PDF Metadata API - Extract PDF Info Programmatically

PDF Metadata Extraction API

Extract metadata from PDF files without any PDF library. Get page count, author, title, subject, and creation date.

Example

curl -X POST http://[2409:893d:dcd:8c60:3058:eb94:1d9:c7fa]:5000/api/v1/pdf/metadata \
  -H "X-API-Key: YOUR_KEY" \
  -F "file=@document.pdf"

Response Example

{
  "pages": 42,
  "author": "John Doe",
  "title": "Annual Report 2024",
  "subject": "Financial Summary",
  "creator": "Microsoft Word",
  "created": "2024-01-15T10:30:00Z"
}

Python

import requests
resp = requests.post(
    "http://[2409:893d:dcd:8c60:3058:eb94:1d9:c7fa]:5000/api/v1/pdf/metadata",
    headers={"X-API-Key": "your_key"},
    files={"file": open("doc.pdf", "rb")}
)
print(resp.json())
