Python Excel Processing Without Local Libraries

Don't want to install openpyxl, pandas, or xlrd in your Python environment? Use our REST API instead.

Instead of installing heavy libraries, just use requests:

import requests

# Clean Excel file — no openpyxl needed!
resp = requests.post(
    "http://[2409:893d:dcd:8c60:3058:eb94:1d9:c7fa]:5000/api/v1/excel/clean",
    headers={"X-API-Key": "your_key"},
    files={"file": open("data.xlsx", "rb")}
)
with open("cleaned.xlsx", "wb") as f:
    f.write(resp.content)

Convert to CSV

resp = requests.post(

    headers={"X-API-Key": "your_key"},
    files={"file": open("data.xlsx", "rb")}
)
print(resp.text)
