Automated Data Cleaning API

Stop writing one-off scripts for data cleaning. Use our API to automate common data cleaning tasks.

What You Can Clean

  • Duplicate rows in Excel files
  • Whitespace — trim leading/trailing spaces
  • Empty cells and rows
  • Encoding issues in CSV files
  • Inconsistent formatting

Excel Cleaning

curl -X POST http://[2409:893d:dcd:8c60:3058:eb94:1d9:c7fa]:5000/api/v1/excel/clean \
  -H "X-API-Key: YOUR_KEY" \
  -F "file=@dirty_data.xlsx" -o clean_data.xlsx

CSV Cleaning

curl -X POST http://[2409:893d:dcd:8c60:3058:eb94:1d9:c7fa]:5000/api/v1/csv/clean \
  -H "X-API-Key: YOUR_KEY" \
  -F "file=@messy.csv" -o clean.csv
