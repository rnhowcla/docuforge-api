CSV to Excel Conversion API

Convert CSV files to formatted Excel (.xlsx) files via REST API. Works with any programming language that supports HTTP requests.

API Example

curl -X POST http://[2409:893d:dcd:8c60:3058:eb94:1d9:c7fa]:5000/api/v1/csv/to-excel \
  -H "X-API-Key: YOUR_KEY" \
  -F "file=@data.csv" -o output.xlsx
