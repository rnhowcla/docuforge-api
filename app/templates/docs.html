Documentation

All requests require an X-API-Key header. Get your key from the dashboard.

Excel Endpoints

POST /api/v1/excel/clean

Upload an Excel file, get back a cleaned version (deduplicated, whitespace trimmed).

POST /api/v1/excel/to-csv

Convert Excel to CSV. Optional sheet_name form field.

POST /api/v1/excel/format

Auto-fit column widths, add header styling.

CSV Endpoints

POST /api/v1/csv/to-excel

Convert CSV to formatted Excel. Optional delimiter field (default comma).

POST /api/v1/csv/clean

Clean CSV: trim cells, remove empty rows.

PDF Endpoints

POST /api/v1/pdf/extract-text

Extract text from PDF. Optional page_range (e.g., "1-3,5").

POST /api/v1/pdf/metadata

Get PDF metadata (pages, author, title).

POST /api/v1/pdf/merge

Merge multiple PDFs. Send multiple files in the files field.

For full API reference with request/response examples, visit the Swagger UI.
