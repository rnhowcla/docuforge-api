Merge PDF Files API - Combine PDFs Programmatically

PDF Merging API

Combine multiple PDF files into a single document with one API call. Supports unlimited files per request.

Example

curl -X POST http://[2409:893d:dcd:8c60:3058:eb94:1d9:c7fa]:5000/api/v1/pdf/merge \
  -H "X-API-Key: YOUR_KEY" \
  -F "files=@chapter1.pdf" \
  -F "files=@chapter2.pdf" \
  -F "files=@chapter3.pdf" -o full-book.pdf

Python Example

import requests

resp = requests.post(
    "http://[2409:893d:dcd:8c60:3058:eb94:1d9:c7fa]:5000/api/v1/pdf/merge",
    headers={"X-API-Key": "your_key"},
    files=[
        ("files", ("a.pdf", open("a.pdf", "rb"))),
        ("files", ("b.pdf", open("b.pdf", "rb"))),
    ]
)
with open("merged.pdf", "wb") as f:
    f.write(resp.content)
